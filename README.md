## 🗂️ Estrutura
O site é publicado pelo GitHub Pages a partir da pasta `docs/`.

```
├── README.md
└── docs/
    ├── .nojekyll
    ├── index.html          # página única do portfólio
    ├── style.css           # estilos (tema escuro, responsivo)
    ├── assets/
    │   ├── foto-perfil.jpg
    │   ├── orb.mp4         # vídeo de fundo
    │   └── projetos/       # screenshots dos projetos ABP
    └── vendor/
        └── inter/          # fonte Inter local
```

## 📝 Padrão de commits
Este repositório segue [Conventional Commits](https://www.conventionalcommits.org/pt-br/):

- `feat:` nova seção ou funcionalidade
- `fix:` correção de conteúdo, link ou layout
- `style:` ajustes visuais/CSS sem mudar conteúdo
- `docs:` alterações no README
- `chore:` assets, configuração e manutenção
